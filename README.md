## ゲームの約束

- **ターゲットはネイティブiOS/Android、3D描画**。ブラウザゲームで代替しない。
- 『Parcel Simulator』（Dansan Digital）の基本ループ（手動搬入、検査、貼付、便別出荷、曜日、倉庫Tier/ライセンス、設置、コンベア、自動化、保管、ショップ）にできるだけ近い機能を制作する。
- **自由歩行キャラクターは廃止**。メニュー・倉庫設備のタップでカメラを即切替し、検査と建設の実作業は残す。
- 建設時は**3D半透明ゴーストをドラッグし、回転・反転・設置可能判定・接続確認**する。
- **荷物/ゲート/Submission/TruckRunを別ID管理**し、カメラ切替で勝手に箱を動かさない。
- オリジナル要素として、ゲーム内時刻に従い外部からトラックが現れ、接車・荷役・退出する様子を確認できる。
- 参考画像に見られる工業倉庫の**リアルな材質・奥行き・アニメーションの品質を目標**とし、固有のモデル・UI・コード・音などは複製せず独自制作する。
- 30fps安定、上位端末で60fps、長時間でも極端な熱低下がないことを狙う。**実機測定前に達成済みと主張しない**。
