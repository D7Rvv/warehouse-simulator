# Warehouse Simulator

スマートフォン（iOS / Android）向けの高品質な3D物流倉庫経営シミュレーションゲーム。

> **設計を更新しました（2026-10-26）。** 最新の基準は [ゲーム全体仕様書 Ver.0.2 — 拠点切り替え方式](docs/GDD_V0_2_STATION_BASED.md) です。

## 最新のゲーム操作方針

- 自由歩行・仮想スティックによるキャラクター移動は**採用しません**。
- 「検査」「仕分け」「倉庫」「出荷」「トラック」「設備」「経営」をメニューからタップし、作業場所の3Dカメラに**瞬時に切り替え**ます。
- 荷物の検査、バーコード確認、重量確認、開封、承認・拒否などの楽しさは維持します。
- コンベア配置や倉庫全体の管理は俯瞰視点を使います。
- ゲーム内時間とトラック運行を連動させます。
- モバイル向けの画質・30fps安定・持続的な発熱抑制を実機で評価します。

## 既存コードの扱い

`Assets/Scripts/Phase1/` の5ファイルは**旧Ver.0.1向けの実験コード**です。自由歩行を含んでおり、現行の正式仕様ではありません。レビュー・移行・削除の判断がつくまで残し、新仕様での実装完了とみなさないでください。
