## 調査の原則
- 元作品（Dansan Digital「Parcel Simulator」）の公開情報で確認できた内容だけを「確認済み」と記す。
- デモ版限定・開発中・更新で追加された項目は分ける。情報源の時点を尊重する。
- 再現するのはゲームシステム・楽しさであり、著作物（モデル・テクスチャ・UI画像・コード）の複製ではない。
- 本プロジェクトは一人称自由歩行を採用しない。機能ごとに**スマホ用の作業場所タップ操作**へ置換する。
