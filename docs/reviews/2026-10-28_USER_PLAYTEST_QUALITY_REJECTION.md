## 1. ユーザーから直接得た事実（引用・要約）
ユーザーはiPhone上で現在の試作品を確認し、以下を述べた。
- 「全然、元モデルと違います」
- 「ゲーム性がない」

- 「初心の人でも何をすればいいのかわからなさすぎる」
- 「全体のクオリティが0.5/10ですね」

この **0.5/10はユーザーによる主観的な体験評価**。ツールで測った定量性能や原作の公式評点ではない。重大な不合格として追跡する。
ユーザーが使ったiPhone表示方式（Unity Remote 5か、ネイティブビルドの配布か）は未確認。**実機性能・熱・FPSの計測完了を主張しない**。
ユーザーは高品質・低発熱・低遅延を同時に求めている。PCは i7-7700 / RAM16GB / Intel HD Graphics 630、iPhone実機は13 Pro Max。PC編集画質とiPhone向け本番画質は別に調整。

## 2. 根本原因の推定・裏付け
**GitHub PR #2の説明とS0/S1レポートを確認した。** そこでは「単一Cameraで場所切替」「読み取り専用Fixture」「半透明配置Preview」「独自の3D仮モデル」のみが実装範囲。荷物の本当の移送/検査合否/貼付/資金/出荷/物流は対象外と明記。
よって以下のように明示して追跡する:
- **観測[USER]**: 初心者に何をすべきか分からない。主要な遊びが無い。3Dが目標水準を大きく下回る。
- **実装範囲[REPO]**: S0/S1は技術土台・3Dブロックアウトであり、実ゲームではない。
- **推定[P]**: チュートリアルと実際のフィードバック/報酬ループがないことが遊びの分かりにくさの主因。低品質はテスト用プロシージャル仮モデルと十分なアート制作工程/レファレンスレビューの欠如。
- **未観測[U]**: iPhoneのビルド方法、fps、熱、描画品質設定、Unity Console全件、プレイ録画/キャプチャ、詳細なクリック数。これらは確定しない。

## 3. プロジェクトの品質ゲート変更
### GATE-PLAYER-00 — **初回操作の明確さ（今後のプレイ可能ビルド必須）**
- 起動時、画面の中心的な目標が一文で表示: 「トラックから荷物を取り、検査して出荷しましょう」。
- 次に押すUI・3D対象が強調表示。ユーザーが完了するまで目的は消えない。
- 操作直後に視覚/音/進捗フィードバック（何を取得し、どこへ運ぶか）がある。
- 何もない画面、どのボタンが有効か不明、未実装ボタンが成功して見える、説明なしの大量メニューは不可。
- 「戻る」「次に何をする？」「やり直し」を実装。目標は簡潔、状況に応じて変わる。初心者の初回タスクは必要最小限のUIのみ表示。
- 新規ユーザーで迷う場所/初回操作時間を試遊記録。プレイヤーの実際の操作で確認する。

### GATE-PLAY-01 — **遊べる完全な一工程（次スプリント必須）**
- **搬入トラック → 1箱取る → 検査台へ置く → ラベル/規則を目視で比較 → Approved/Deniedを手動貼付 → 対応ゲートへ運ぶ → 出荷確定 → 結果/報酬** の往復を、見た目の切替ではなく唯一のPackageIdの所有権移動として実装。
- 最低3種類のTestParcel（正常/国旗不一致/輸送区分違い）に対して、正しい判定と誤った判定の結果を分ける。
- 箱を取ったときトラックの箱が1個消え、検査台に実際に現れ、ゲートが受け取る。どこかへ消えたり複製したりしない。
- ルールは最初Cargo/Countryから始める。重量/番号/内容物/スタンプはLicenseごと後続スプリントで段階追加。表示上だけある未実装操作を提供しない。
- 収益の係数が原作未確認ならTestFeePolicy [P] と表示/データ区別し、**検査や所有権だけは本物**。通常の経営結果を誤表示しない。
- Save/Load、前画面へ戻る、誤操作時の復元、二重入金/箱の複製防止をテスト。

### GATE-ART-01 — **参照に匹敵する視覚品質の制作工程（次スプリントから必須）**
参考資料: `docs/THREE_SCREENSHOTS_ACCEPTANCE_SPEC.md` (IMG_0179入荷トラック / IMG_0180建設コンベア / IMG_0181出荷ゲート)、`docs/spec/12_ASSET_ART_DIRECTION.md`。
- 入荷: 荷台内壁・床・シャッター・バース・紙の段ボールとテープ/印刷ラベルが、プロップ単位で識別できる3D。
- 検査: 近景の箱・ラベル・台・秤/スキャン機器が適切な工業素材、スケール、細かいベベル、AOや接地影を持つ。
- 出荷: 保護柵/搬送ベルト/ゲート枠/表示モニター/貨物アイコンに厚みと読み取りやすい情報がある。
- コンベア: ゴーストだけでなく実設備にローラー/脚/接続口/ベルトの進行方向。角張った単純Cubeの寄せ集めを完成モデルと呼ばない。
- 光、材質、距離感、UI情報構造について参照画像と**並べて人間がレビュー**する。形状やアセットを直接コピーせず独自デザインで同等の品質を目指す。
- アセットを`ART_ASSET_MANIFEST`で管理し、Prefabのモデル/材質/法線/UV/LOD/ライセンスと軽量版を追跡。
- iPhone横画面のGameViewスクリーンショット（画面ごと）、見える機器の一覧、低画質Editorとの比較をPRに添える。**実画像がないのに視覚受入PASSにしない**。

### GATE-PERF-01 — **低熱・低遅延**
- PC内蔵GPU用`EDITOR_LOW`と端末用`MOBILE_BALANCED`を分離。PCで粗く表示されても、iPhoneの本番画質を固定的に落とさない。
- CPUロジックとレンダリングを分離、固定Tick、Shared Mesh/Material、GPU適正DrawCall、静的照明、必要最低限Shadow、Cull/LOD、動的Boxはpool利用。
- iPhone 13 Pro Maxでネイティブアプリが実行できるまで、FPS/熱/電池は`NOT_RUN`。Unity Remoteの画質をネイティブ画質の数値保証にしない。
- ネイティブの代表的な30分連続試験、p95/p99 frameTime、OS thermalStatus、Memoryの経時変化が揃うまで「低発熱合格」と宣言しない。
