# ゲームループ・チュートリアル・解放進行
文書ID: SPEC-02 / 対応: REF-001..021,037..049 / 状態: 一部[P]

## 核心
初期プレイヤーは自分でトラックの荷台から箱を選択し、検査台に置き、ラベルを検査して緑/赤の結果を貼り、曜日に対応した出荷口/拒否口まで移す。儲けた資金で機器・搬入自動化・ライン・スキャナー・ラック・出荷のアップグレードを解放する。[R/S1,S3,S4]

## 1日の順序
DAY_START → 検査ルール表示/出荷カレンダー表示 → シャッター開放（トラック入荷開始） → 手作業または自動搬入 → 検査 → 仕分け → ラック保管or出荷口投入 → 出荷集計/報酬 → 17時時点の新規入荷停止[2025R] → 在庫/注文/ライン調整 → 就寝コマンド → DAY_CLOSE（確定・セーブ）→ NEXT_DAY。
- 17時営業終了は2025攻略の確認値。2026年の時計仕様と翌日の配送待ちの扱いは要検証。
- 「検査中にメニューを開く」は物流処理を止めない。ただし明示的なPause/Sleepは別処理。
- DAY_CLOSEは同一日に二回実行されないイベントIDで保護。
- 未出荷荷物がある状態でもセーブ・翌日持ち越しを許す。ラックの容量以上に在庫がある場合の追加挙動は[P]。
- 本編はエンドレス経営。ゲームオーバー・破産・契約ペナルティの原作の詳細は未確認、独自の運営費を勝手に追加しない。

## 進行の骨格（具体Tier番号は原作照合前にロックしない）
| 段階 | 検査手動 | 自動化 | 倉庫設備/出口 | プレイヤーに残る判断 |
|---|---|---|---|---|
| 序盤 A | 貨物種類/国旗の目視・ステッカー | なし | 搬入1/検査台/少数の出荷口 | 正誤と配送方法 |
| 序盤 B | 重量・番号（購入ライセンスで追加） | 最初の直線ベルト | 単純ライン、スケール/キーパッド | 流量と価格 |
| 中盤 A | 内容物/スタンプ | スキャナーのValid/Invalid分岐 | Joiner、Sticker Checker、Diverter | 検査漏れと接続 |
| 中盤 B | 例外だけ手作業 | Auto unload、sticker貼付、出荷自動 | ラック＋Loader/Unloader、上位Tier出口 | 曜日・滞留対応 |
| 後半 A | 特殊異常だけ確認 | 高速ライン・複数投入・出荷 | 複数ベイ・大型倉庫 | ボトルネック解消 |
| 後半 B | 国別Expressの例外確認 | Country Diverter、Elevator、Pallet Build Mode | 新倉庫の上下階/国別ゲート | 週次国カレンダー |

**[R/2025参考]** 古いガイドでは「初期10×20 conveyor単位の広さ、段階的に10×10拡張、最初の倉庫拡張が重量秤+重量ライセンス購入後に$700、14段階」という記述あり。2026の新倉庫を含む最新Tier体系へそのまま当てはめない。[S5]
**[R/2026公式]** Pallet Build Modeは旧パッチ後Tier 11で解放、Auto PauserはTier 15で解放・価格$30,000。新倉庫での実際の上限と前提Tierの意味は照合が必要。[S2]

## ライセンス・Tier・アップグレードの違い（モデルは混ぜない）
- License: 検査するルール項目を追加、荷物単価に影響。購入しなければ不要な検査条件は発生しない（2025資料）。
- WarehouseTier: ショップ品・倉庫スペース・ベイ・設備グレードを解放。必要ライセンスと資金などのAND条件で進行。[P:全要求式]
- Upgrade: `ConveyorDeliveries`, `AutomaticExports`, `PalletBuildMode`, `RackSigns` 等、購入後に機能が使用可能。
- EquipmentLevel: 機械個別レベル。購入=設置/配置開始、アップグレード=同一機械の速度/性能変更。
- WarehouseProfile: オリジナルの貨物別出荷倉庫と、国別Express倉庫を分離。異なるカレンダーと出荷先ロジック。

## チュートリアル（勝手な数値は[P]）
TUT-01 3D搬入口へタップ切替、トラック荷台の箱を一つタップ。
TUT-02 「手に持つ」状態を作り、検査ステーションへ移る（キャラ移動不要）。
TUT-03 伝票を拡大して貨物マーク/国旗を検査、基準表で照合する。
TUT-04 承認/拒否を選択。緑と赤を両方体験できる教材荷物を用意。
TUT-05 対応する出荷口（または拒否ゲート）へ箱を移す。正誤・報酬を表示。
TUT-06 [ショップ]で設備を1個購入し、ゴースト配置→回転→接続→設置。
TUT-07 設備を通った荷物を確認、ライン停止時は原因を見つける。
TUT-08 倉庫画面から次のTier・ライセンスの条件を確認する。
各ステップは端末を閉じても進捗保持。初回スキップ時はチュートリアル用の特殊荷物を日常荷物に混ぜず処理して終える。

## 成長の楽しさを維持する具体ルール
- 自動化前に一度は手動の「検査・出荷」を体験する。
- 自動化によって *作業量が減り、受入量が増え、詰まりが生まれ、それを設備配置で解決する* という新しい遊びが生じる。
- ラックは「いつでも出荷できる」簡略保管にならず、曜日の出荷制限と組み合わせる。
- スキャナー導入後も、内容物検査や書類異常などは解放段階に応じてプレイヤーが対応できる。
- ただメニューで「自動化」ボタンを押すだけでは動かず、配線・方向・出口設定をプレイヤーが理解して設置する。

## 設定値とコンテンツのデータ駆動
- `ProgressionCatalog`: 全unlock ID、前提License/Tier/Upgrade、費用、解禁画面、説明文字列、適用WarehouseProfile、根拠。
- `InspectionRuleSet`: 免許ごとのActiveRule IDs、正解生成重み、1個当たり追加売上。
- `WarehouseTierCatalog`: Tier ID、敷地拡張マップ、解除機材、買い物カテゴリ、便/出口/追加ベイ。
- ルール変化はセーブ時に`catalogVersion`を保存し、古いデータもマイグレーションできるようにする。

## 例外・進行不能の防止
- 所持金が低くても手動で箱を正しく処理して資金再獲得可能な最小ルートを維持。
- 持っている道具を売却/撤去して日替わり検査ができなくならないよう、購入済みLicenseに対応する手動代替手段を保持するか売却を禁止[P]。
- 新WarehouseProfile解放後、旧倉庫在庫を新倉庫へ強制移動しない。各WarehouseIdで所有関係を管理。
- 末日の保留在庫の清算を想像で実装しない。原作実機で就寝ルールを確定する。
- 収益額・Tier数・契約条件・購入価格の詳細はSPEC-08/14で管理。

## チュートリアル受入
ACC-PRG-01 新規開始から1荷物を出荷し、収益確定・次荷物へ進める。
ACC-PRG-02 再起動後も初回進行ステップと購入機材が維持される。
ACC-PRG-03 レベルアップで未解放だった機材がショップに現れる。
ACC-PRG-04 無理にライセンスを買わなければその検査項目は強制しない。
ACC-PRG-05 すべての搬送設備を撤去しても最小の手動ルートへ復帰可能。
ACC-PRG-06 第2倉庫解放後、OldとRegionalで輸送ルールが混ざらない。
